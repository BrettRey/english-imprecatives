## Forms × candidate understood subjects

✗ = excluded, ✓ = compatible, ? = excluded only if the pronoun is referential.

| Form | Example | Addressee (imperative) | Speaker (reduced performative) | Third person (optative) | None (B, C, D) |
|---|---|---|---|---|---|
| Y: *you*, interlocutor necessarily present | *Damn you for asking for it!* (TV, *Babylon 5*) | ✗ binding: would need *yourself* | ✓ *I damn you* | ✓ *God damn you* | ✓ |
| Mr+: referential *me*, someone present | *Damn me for agreeing to it* (TV, *Babylon 5*); *Fuck me for giving a shit* (TV, *Shameless*) | ✓ imperative *(you) damn me* | ✗ binding: would need *myself* | ✓ | ✓ |
| Mr0: referential *me*, no one present | *…and found myself alone. Tricked. Damn him. And damn me for falling for it.* (COCA, FIC 2006, Kelley Armstrong, *Broken*, Bantam; narration states the narrator is alone); *Damn me for shooting my mouth off that night* (COCA, FIC 2007, Jablokov, "Brain Raid", *Fantasy & Science Fiction* 112(2); first-person narration, addressed to no one in the scene); *Fuck me for being an idiot!* muttered alone: possible (Brett, 2026-11-23: "maybe"); *Damn me for forgetting the keys!* muttered alone: odd (Brett) | ✗ no addressee | ✗ binding | ✓ (but overt *God* nearly absent on *fuck*) | ✓ |
| Mb0: bleached *me*, no one present | *Fuck me!* on dropping something heavy (constructed; Brett's judgment that it's valid alone) | ✗ no addressee | ? | ✓ | ✓ |
| Mb+: bleached *me*, someone present | *Is it yourself? Well, fuck me!* (COCA, FIC 1991) | ✓ | ? | ✓ | ✓ |
| T: third-person pronoun or lexical NP | *Damn him!*, *Damn the bell!* | ✓ | ✓ | ✓ | ✓ (no binding information) |
| I: *it* | *Damn it!* | ✓ | ✓ | ✓ | ✓ (no information) |

Caveats:
- **Apostrophe.** A speaker alone can address fate or God. An addressee subject of that kind is the third-person optative source under another name, so it doesn't rescue the imperative analysis.
- **Binding** assumes the object pronoun is a referential co-argument of the understood subject. Bleached *Fuck me!* may not meet that, hence "?".
- **Solitary use is a judgment.** Corpus lines can't show that no one was present, so rows Mr0 and Mb0 rest on introspection, not on the corpora.

## Consequences for the paper (applied 2026-11-23)

1. The speaker-subject test needs **referential** *me*. The paper cited *Fuck me!* / *Bugger me!*, which are mostly bleached. Cite the TV self-curses instead (*Damn me for agreeing to it*, *Fuck me for giving a shit*).
2. "Where *me* is referential, only a third-person subject or none fits" was wrong: that holds only for Mr0 (referential and alone). Mr+ still allows an addressee subject.
3. The solitary argument's job is to exclude the **mixed** analysis. Ruling out a single addressee or speaker subject needs only Y and Mr+, so the abstract and conclusion shouldn't credit it to solitary use.
4. The solitary bleached case (Mb0) excludes only an addressee subject.

5. After Brett's judgment (2026-11-23), §6.1 marks the solitary self-curse as introspective ("to my ear"), uses *fuck* rather than *damn*, and draws the consequence for *fuck* only. A COCA fiction query on `fuck|damn|screw|curse me for`, checked for solitude cues in the narration, would test it.
