# English imprecatives preprint

Posted as [LingBuzz 010557](https://ling.auf.net/lingbuzz/010557) on 24 November 2026.

The public PDF contains the 24 November 2026 article submitted to *English Language and Linguistics*, with author details restored, followed by its exact supplementary PDF. The abstract and main argument match the submitted version; the data-availability statement links to the accompanying replication archive. This is a preprint, not an accepted manuscript.

The replication ZIP is the same archive supplied with the journal submission. It contains analysis scripts, saved aggregates and text-free adjudication labels and source identifiers. Restricted corpus text and concordance exports are excluded. Its README explains the portable checks and which operations need licensed corpus access.
